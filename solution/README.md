# 难点与测试对应

## 难点 1：纯延迟 θ 必须搜出来

推理轴：数值方法

落在推理路径上的哪里：θ 是边界参数，落在阶跃之后、响应开始之前那一段，只影响那一段时间窗内的残差。原实现直接把 θ 当成 0，于是 τ 和 K 都被拉偏，整定出来的控制器就振荡了。正确做法是在 (θ, τ) 上做二维搜索：先粗网格定位，再在 θ、τ 上分别用黄金分割细化，给定 (θ, τ) 时 K 有闭式最小二乘解。θ 小时（几个采样周期）也一样要估出来，不能给零。

对应测试：test_delay_estimated_from_grid_search、test_short_delay_run_still_estimated

## 难点 2：传感器卡死段要整段剔除

推理轴：数据口径

落在推理路径上的哪里：读数连续多个点完全相同时是传感器卡死，不是真实温度（有噪声时真实读数几乎不可能逐点相同）。这些点既不能进基线均值，也不能进拟合，否则残差被拉平、θ 和 τ 都偏。原实现没有这一步，报告里的剔除点数也没有。

对应测试：test_frozen_segment_removed_from_fit

## 难点 3：基线、阶跃幅度与增益的量纲

推理轴：领域公式

落在推理路径上的哪里：K 是单位输入变化引起的稳态温升，要先用阶跃前窗口的均值定 y0、用实测输入之差定 Δu，再把最小二乘出的总升幅除以 Δu。原实现拿阶跃前最后一个点当基线、拿最后一个采样点当稳态，噪声一点就偏好几个百分点；如果输错单位或少除 Δu，报告里那一栏就整体差一个量级。

对应测试：test_gain_and_tau_match_independent_fit、test_second_run_with_other_parameters

## 难点 4：参数不确定度要把非线性参数算进去

推理轴：数值方法（Gauss-Newton 协方差）

落在推理路径上的哪里：参数协方差 = `sigma_hat²·(JᵀJ)⁻¹`，`J` 必须包含 θ 与 τ 两列（增益乘响应函数对这两个参数的偏导）。把 θ、τ 当成已知量、只对增益求方差，滞后与时间常数的标准误会明显偏小，整份不确定度预算就是错的；这两栏还要求保留四位小数，位数与数值都要对。

对应测试：test_parameter_uncertainties_reported

## 跨运行状态（重复运行与不污染）

同一份记录重复运行，报告逐字节一致（不能写时间戳）；运行失败时不能覆盖上一次的报告：先写临时文件再原子替换，非法记录以退出码 2 收场且不落文件。对应测试：test_rerun_produces_identical_bytes、test_failed_run_keeps_previous_report。

拟合质量另有 test_rmse_reflects_fit_quality 单独覆盖（rmse 要落在噪声量级、且与独立复算一致）；输出结构由 test_report_schema_and_rounding 覆盖。

## 权重口径

10 条计分测试 + 1 条门禁（`test_invalid_runs_rejected_without_output`，不通过则整份记 0），权重和 = 1。权重最高的三项是 增益与时间常数 0.154、延迟估计 0.144、不确定度 0.120；逐条权重与理由写在 `tests/scoring.json` 里，其余各项按领域重要性递减分配：核心拟合与不确定度 > 边界与拒收 > 输出契约与重复运行。

## 定标依据（自检用）

判分侧独立做一次 (θ, τ) 网格加黄金分割细化（网格密度与细化路径与参考解不同），在同一份记录上两者参数一致到 0.1% 量级，三个不确定度一致到 3% 以内。本地实测参考解 1.000000、缺陷版 0.000000；缺陷版把延迟固定成零、不剔卡死段、没有不确定度、报告里带运行时间戳，14 条测试全挂（10 条计分 + 门禁的参数化四例）。
